# Superstore SQL Analysis

## Project Overview
This project analyzes the Sample Superstore dataset using SQL Server.

## Dataset
The dataset contains sales, profit, customer, product, regional, and return information.

## Tools Used
- SQL Server
- SSMS
- GitHub

## Analysis Covered
- Sales and profit analysis
- Regional and category analysis
- Customer analysis
- Returned orders analysis
- Year-wise and month-wise sales analysis
- Profit margin analysis
- Discount analysis
- Ranking using Window Functions
- Customer and product performance analysis

## SQL Concepts Practiced
- SELECT
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- JOIN
- CTE
- CASE WHEN
- Aggregate Functions
- Window Functions
- ROW_NUMBER()
- RANK()
- LAG()
- DATEPART()
- DATENAME()

The SQL file contains 30 business-oriented questions and their solutions.
